# Vectorfall

A wireframe space trading and combat game that runs in your browser. One HTML file, no dependencies, nothing to install.

**[Play it here](https://finity-labs.github.io/vectorfall/)** — or download `index.html` and open it locally; it works straight from a `file://` URL.

**[Read the flight manual](MANUAL.md)** — the full handbook, the way game boxes used to include one.

Inspired by the 1984 classic Elite. All code and content are original.

## The game

You start with a small ship, a handful of credits and a laser. Trade goods between star systems, take on missions, upgrade your ship and fight off pirates across procedurally generated galaxies. Smuggle past Warden patrols if the honest margins bore you. Progress saves automatically in your browser.

Nine built-in universes reskin the whole game — goods, ships, worlds and colours — straight from the title screen, and "Today's universe" deals everyone the same unknown galaxies each day.

## Controls

| Key | Action |
|-----|--------|
| Arrow keys | Pitch and roll |
| A / D | Roll |
| W / S | Throttle |
| Space | Laser |
| T | Missile |
| E | ECM |
| B | Energy bomb |
| X | Jettison cargo |
| Shift | Boost |
| C | Dock / docking computer |
| M | Chart |
| J | Hyperspace (follows a plotted route) |
| G | Galactic hyperdrive |

Touch controls work on phones and tablets.
